# Tests automatisés – Projet Homey

Cette section présente les tests automatisés réalisés avec Robot Framework et Selenium pour les User Stories US-07 et US-08.

Les scénarios couvrent notamment le processus de réservation, sa confirmation, son annulation et le paiement.

Les résultats d'exécution, les échecs rencontrés et leur analyse sont présentés dans le dossier [resultats_execution](resultats_execution/).
