# Résultats d'exécution – Tests automatisés Homey

## Présentation

Cette section présente les résultats des tests automatisés réalisés avec Robot Framework et Selenium dans le cadre du projet Homey.

Les tests portent sur les fonctionnalités des User Stories US-07 et US-08.

## Analyse des résultats

Les exécutions permettent d'identifier les scénarios réussis ainsi que les échecs rencontrés.

Les échecs sont analysés afin de distinguer les anomalies fonctionnelles de l'application des problèmes techniques liés à l'automatisation.

## Outils utilisés

- Robot Framework
- Selenium
- Python
