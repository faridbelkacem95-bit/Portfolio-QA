# Résultats d'exécution – Tests automatisés Homey

## Présentation

Cette section présente le suivi et l'analyse des tests automatisés
réalisés avec Robot Framework et Selenium dans le cadre du projet Homey.

Les tests concernent les User Stories US-07 et US-08, notamment
la réservation, sa confirmation, son annulation et le paiement.

## Suivi des tests

Le fichier `Suivi_Tests_Automatises_Homey.xlsx` permet de consulter :

- Les cas de test automatisés
- Les résultats d'exécution (PASS / FAIL)
- Le suivi des tests dans le temps
- Les anomalies rencontrées

## Analyse des résultats

Les campagnes de tests ont permis d'identifier des scénarios réussis
ainsi que des échecs nécessitant une analyse.

Une exécution des tests de paiement 
présentait deux échecs techniques.

Le tableau de suivi documente également des résultats PASS
enregistrés.

Ces résultats illustrent l'importance du suivi des exécutions,
de l'analyse des échecs et de la vérification des corrections.
