# Ressources des tests automatisés – Homey

Ce dossier regroupe les ressources communes utilisées par les scénarios de tests automatisés.

- `keywords.resource` : mots-clés réutilisables pour les actions et vérifications.
- `variables.robot` : variables de configuration des tests.
- `locators.py` : sélecteurs des éléments de l'interface utilisateur.

Ces ressources permettent de faciliter la maintenance et la réutilisation des tests.
