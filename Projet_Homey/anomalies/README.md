# Gestion des anomalies – Projet Homey

## Présentation

Cette section présente les anomalies identifiées lors des campagnes
de tests fonctionnels du projet Homey.

Les anomalies ont été documentées et suivies dans Jira, dans le cadre
des User Stories US-07 et US-08.

## Anomalies identifiées

Cinq anomalies ont été documentées :

| Référence | User Story | Description | Sévérité |
|---|---|---|---|
| AN-001 | US-07 | Champ de message absent | Majeur |
| AN-002 | US-07 | Notification hôte absente | Majeur |
| AN-003 | US-07 | Problème de sélection des dates | Mineur |
| AN-004 | US-08 | Paiement possible sans profil de paiement hôte | Bloquant |
| AN-005 | US-08 | Paiement possible après annulation | Bloquant |

## Méthode de gestion des anomalies

Chaque anomalie a été documentée avec :

- Une référence unique
- Une description du dysfonctionnement
- Les étapes de reproduction
- Le résultat attendu
- Le résultat obtenu
- Une évaluation de la sévérité
- Un lien avec le cas de test concerné

## Outils utilisés

- Jira : déclaration et suivi des anomalies
- Xray : traçabilité entre les tests et les anomalies

## Objectif

Démontrer ma capacité à identifier, analyser, documenter et suivre
les anomalies détectées pendant une campagne de tests logiciels.
