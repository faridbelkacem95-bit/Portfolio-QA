# Tests manuels – US-08

## Présentation

Cette section présente les livrables de conception et d'exécution des tests fonctionnels de l'US-08 – Traiter une demande de réservation, dans le cadre du projet Homey (PFF).

## Travaux réalisés

- Analyse de la User Story et des critères d'acceptation
- Conception et préparation des cas de test
- Implémentation et exécution des tests manuels
- Analyse des résultats d'exécution

## Résultats d'exécution

- **20 cas de test exécutés**
- **17 tests réussis (PASS)**
- **3 tests en échec (FAIL)**
- **Taux de réussite : 85 %**
