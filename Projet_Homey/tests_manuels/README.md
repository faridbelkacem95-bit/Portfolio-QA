# Tests manuels – Projet Homey

## Présentation

Cette section présente les tests fonctionnels manuels réalisés dans le cadre du projet Homey, projet de fin de formation (PFF).

Le périmètre couvre deux User Stories :

- **US-07 (P1)** – Faire une demande de réservation
- **US-08 (P2)** – Traiter une demande de réservation

## Démarche de test

- Analyse des User Stories et des critères d'acceptation
- Conception et préparation des cas de test
- Implémentation et exécution des tests manuels
- Gestion et suivi des cas de test avec Xray
- Identification et suivi des anomalies dans Jira
- Analyse des résultats d'exécution

## Résultats de la campagne

| User Story | Tests exécutés | PASS | FAIL | Taux de réussite |
|---|---:|---:|---:|---:|
| US-07 | 12 | 10 | 2 | 83,3 % |
| US-08 | 20 | 17 | 3 | 85 % |
| **Total** | **32** | **27** | **5** | **84,4 %** |

Les 32 cas de test prévus ont été exécutés, soit 100 % du périmètre de test.

Cinq anomalies ont été identifiées : deux bloquantes, deux majeures et une mineure.

## Bilan qualité

Les deux User Stories ont été déclarées non conformes aux critères qualité définis.
