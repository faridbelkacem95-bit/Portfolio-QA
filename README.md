# Portfolio QA – Test logiciel

Bienvenue sur mon portfolio GitHub consacré au test logiciel et à l'assurance qualité (QA).

Ce portfolio présente les projets que j'ai réalisés au cours de ma formation en test logiciel, à travers des activités de tests manuels, de tests automatisés et de gestion des anomalies.

## Mes projets

### 1. Projet Homey – Projet de fin de formation (PFF)

Ce projet de fin de formation porte sur les fonctionnalités de réservation d'une application web. Il m'a permis de mettre en pratique les compétences acquises durant ma formation en test logiciel.

Travaux réalisés :

- Analyse des User Stories US-07 et US-08
- Conception et exécution de tests manuels
- Gestion et suivi des cas de test avec Xray
- Automatisation des tests IHM avec Robot Framework et Selenium
- Tests des parcours de réservation, confirmation, annulation et paiement
- Identification et documentation des anomalies dans Jira
- Suivi et analyse des résultats d'exécution
- Rédaction du rapport de test final

[Consulter le projet Homey](Projet_Homey/)

### 2. Projet Transverse – Projet réalisé au cours de la formation

Ce projet, réalisé au cours de ma formation en test logiciel, m'a permis de découvrir et de pratiquer différents niveaux et types de tests logiciels.

Travaux réalisés :

- Tests unitaires avec Python et Unittest
- Tests API avec Robot Framework
- Tests IHM avec Robot Framework et Selenium
- Automatisation de scénarios de connexion
- Création de scripts pour lancer les tests
- Rédaction du rapport de test final

[Consulter le projet Transverse](Projet_Transverse/)
